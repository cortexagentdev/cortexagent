- Independent security review remains outstanding as documented in `../SECURITY-AUDIT.md`.

## Registration validation

All four presets passed the repository registration CLI with pinned transaction hashes, canonical receipts, approved calldata, events, immutable policies, factory slots, deployed code, and confirmations. `4663.transactions.json` contains the pins. Nitro factory slots store parent-chain heights (`l1BlockNumber`); the manifest and indexer use execution-chain receipt heights (`blockNumber`). The off-chain verifier now handles both explicitly; Solidity was unchanged. Regression and deployment safety tests: 44 passing; API type-check and targeted lint passed.
